# Qt Calculator

A simple calculator application developed using **C++ and Qt**.

## About the Project

This project is a beginner-friendly desktop calculator built to practice C++ programming and GUI development with Qt.

## Features

- Basic arithmetic operations
- Addition, subtraction, multiplication, and division
- Input validation
- Error messages for invalid operations
- Division-by-zero protection

*Note: Keep only the features that are actually implemented in your calculator.*

## Technologies Used

- C++
- Qt Framework
- Qt Creator

## How to Run

1. Clone or download this repository.
2. Open the project in Qt Creator.
3. Open `CMakeLists.txt` or the `.pro` project file, depending on your project.
4. Configure the project using an installed Qt kit.
5. Build and run the application.
